# Training & Drills

## Overview
To keep players engaged between tournaments, this module provides structured practice routines. It turns "throwing darts" into "training with a purpose".

## Core Drills (MVP)

### 1. Bob's 27 (Doubles Practice)
*   **Goal**: Hit specific doubles in order (1 to 20 + Bull).
*   **Rules**: Start with 27 points. Hit the double -> Add value. Miss -> Subtract value. Drop below 0 -> Game Over.
*   **Why**: The industry standard for practicing doubles (finishing).

### 2. Round the Clock (Accuracy)
*   **Goal**: Hit 1, then 2, then 3... up to 20 + Bull.
*   **Variants**:
    *   *Singles*: Hit the fat part.
    *   *Doubles/Triples*: Hard mode.
*   **Scoring**: Count how many darts it takes to complete the cycle.

### 3. Scoring 99 (Power Scoring)
*   **Goal**: Throw 99 darts at T20.
*   **Stats**: Count how many T20s, S20s, 5s, 1s.
*   **Output**: "Scoring Efficiency" rating.

## Integration with Profile
*   **Personal Bests**: "My best Bob's 27 score is 143".
*   **Progress Tracking**: Graph showing improvement in "Round the Clock" speed over time.
